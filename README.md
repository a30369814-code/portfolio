# Abubaker Baobaid — Portfolio Studio V2

A bespoke, editorial-style portfolio built with HTML, CSS and JavaScript. No runtime framework or build tools required.

## Run locally

Open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 5500
```

Then visit http://localhost:5500. A local web server is preferred for testing.

## Features
- English and Arabic translation and RTL layout
- Responsive layouts for desktop, tablet and mobile
- Filterable case studies with accessible details dialog
- Project descriptions grounded in publicly accessible GitHub READMEs
- Portfolio achievement cards and real Dean's List photo
- Direct email and phone links; GitHub and LinkedIn links
- Subtle reveal motion, accessible focus states, reduced-motion support
